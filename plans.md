# Plans for GNOME Online

   2. Add an argument to Nautilus to make it function as a file picker (I.E. Pass the file
      selected back to the program that called it, instead of opening it normally)
2. Modify Text Editor
   1. Add the option to change the font
   2. Add an open button
3. Better APIs

4. Add multi-tab functionality to Epiphany
5. Markdown Editor App
6. Make Loupe show an open menu when called without an argument.
7. Some sort of Settings app
   1. Proper UI for setting username & password
   2. Proper UI for toggling login
   3. Multiple tabs for different settings
   4. UI to toggle Dark Style
   5. UI to change Accent colour
   6. UI to change wallpaper
8. Add Notifications system
9. Add way to permanently install apps
